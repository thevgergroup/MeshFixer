# MeshFixer 0.1.1

MeshFixer is now open source, and Windows has its own download.

## Downloads

| File | For |
|---|---|
| `MeshFixer-0.1.1-macos.zip` | macOS on Apple silicon. Signed with a Developer ID, not yet notarized. |
| `MeshFixer-0.1.1-windows-x64.zip` | Windows 10 and 11, 64-bit. Not code-signed yet. |

**macOS:** unzip the file and move MeshFixer.app to Applications. Open it once, then go to System Settings › Privacy & Security and click Open Anyway.

**Windows:** extract the zip and run `MeshFixer.exe`. If SmartScreen warns you, click More info, then Run anyway.

The `meshfixer` command-line tool comes with both downloads:
- **macOS:** `MeshFixer.app/Contents/Resources/bin/meshfixer`.
- **Windows:** `cli\meshfixer.exe`.

## What's new

- **A Windows build.** The app and CLI are built on GitHub by `.github/workflows/release.yml`. The app has the rabbit icon and opens without a console window.
- **Open source.** MeshFixer is licensed under either MIT or Apache-2.0, at your option.
- **A new README,** written for people using the app, with screenshots.

All 0.1.0 features are unchanged: repair, split, connectors, combine, hollow, sculpt, the parts library and typed units. See the [0.1.0 notes](v0.1.0.md).

## Known issues

- **The Windows build is new, and hasn't been tried by hand on many machines yet.** Please [report problems](https://github.com/thevgergroup/MeshFixer/issues).
- There's no Linux download yet. Build it from source.
- On macOS, Finder's "Open With" isn't supported yet.
- The interface can stutter while filling holes on 5-million-triangle models (MF-ISSUE-118).
- Some long names in the Parts library are cut off (MF-ISSUE-119).
