# MeshFixer 0.1.2

Windows now has an installer.

## Downloads

| File | For |
|---|---|
| `MeshFixer-0.1.2-windows-x64-setup.exe` | Windows 10 and 11, 64-bit. **The installer (recommended).** Not code-signed yet. |
| `MeshFixer-0.1.2-windows-x64.zip` | Windows 10 and 11, 64-bit. Portable: extract and run, nothing installed. |
| `MeshFixer-0.1.2-macos.zip` | macOS on Apple silicon. Signed with a Developer ID, not yet notarized. |

**Windows installer:** run the setup file. It installs for your user account, so it doesn't ask for admin rights. If SmartScreen warns you, click More info, then Run anyway.

**Windows zip:** extract it and run `MeshFixer.exe`.

**macOS:** unzip the file and move MeshFixer.app to Applications. Open it once, then go to System Settings › Privacy & Security and click Open Anyway.

## What's new

- **A Windows installer.** It adds:
  - a Start menu shortcut, plus a desktop shortcut if you want one;
  - an uninstaller in Settings › Apps;
  - MeshFixer under **Open with** for `.stl`, `.obj` and `.3mf` files. Your current default app for those files stays the default.
- **Same app, different packaging.** MeshFixer itself works the same as in 0.1.1. The command-line tool is in `cli\meshfixer.exe`, in the install folder.

## Known issues

These are unchanged from [0.1.1](v0.1.1.md):
- There's no Linux download yet. Build it from source.
- On macOS, Finder's "Open With" isn't supported yet.
- The interface can stutter while filling holes on 5-million-triangle models (MF-ISSUE-118).
- Some long names in the Parts library are cut off (MF-ISSUE-119).
