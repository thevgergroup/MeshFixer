# MeshFixer 0.1.0

This is the first packaged release: a macOS app bundle with an icon, plus the `meshfixer` CLI inside it.

## What's in it

- **Repair:** inspect a model and fix holes, near-duplicates and small parts. Make solid fixes models that overlap themselves.
- **Split:** cut by a plane (horizontal, vertical or tilted), by the print-volume box, or by region. Choose to keep the part above, the part below, or both. The cut can be capped, or left open for vases. Cutting a 30M-triangle model takes about 1.4 s.
- **Connectors:**
  - pegs, round or square;
  - dowels;
  - dovetails that run to the edge;
  - hinges, including the print-in-place hinged box;
  - clasp, flap and thread;
  - teardrop holes.

  Clearance comes from the fit class, and tolerance from the machine profile.
- **Combine:** Tinkercad-style combining, where each part is either a Solid or a Hole.
- **Hollow:** set a wall thickness, add drain holes, or open the shell through a picked face.
- **Sculpt:** brush strokes where the brush size is set on screen.
- **Align, Transform and Parts library:** the snap step follows your zoom, and Snap can be turned on or off.
- **Units:** this release fixes units throughout the app.
  - Every length field accepts expressions such as `5 cm + 2 mm`.
  - When you import a model, MeshFixer picks the unit that makes it fit the plate. It also remembers your choice for each folder.
  - Inspect has Reinterpret and Scale controls for units.
  - Export always writes mm.
- **Refusals:** when a tool refuses an operation, the explanation appears in that tool's panel, with a next-step button.
- **History:** every step has a readable label, and undo and redo work for every operation.
- **Esc:** cancels the drag in progress in every tool.

## Install (macOS)

1. Unzip `MeshFixer-0.1.0-macos.zip`.
2. Move `MeshFixer.app` to Applications.
3. The first time, open it with right-click, then Open. The app is not signed or notarised yet.
4. To open a model, use File > Open, or drop the file on the window.

## Known issues

- On Linux and Windows the app builds, but it hasn't been checked by hand.
- Finder's "Open With MeshFixer" isn't supported yet.
- The UI can stutter while Fill holes runs on a 5M-triangle model: its worst frames take 58–78 ms (MF-ISSUE-118).
- The UC3 clasp shows no latch engagement yet.
- The architecture consolidation (`docs/architecture-as-built.md`) is part-way through. Split and Connect still compute part of their preview inside the app.

## Manual smoke list (about 15 minutes, on `MeshFixer.app`)

1. Open `fixtures/real/stanford-bunny.obj`. The import dialog should pick **Metres**, giving 156 mm, labelled "fits".
2. **Inspect:** lengths are shown with units, never "0.0000".
3. **Split:** drag the plane. It should move by millimetres, and Esc should cancel the drag. Choose Keep both, then Apply. You should get two capped parts.
4. **Connect:** add two dowels across the cut, then Apply. Undo should remove them.
5. **Combine:** mark one object as a Hole, then Combine. The hole is cut. Undo restores it.
6. **Hollow:** use a 2 mm wall and pick the bottom face to open through, then Apply. History should read "2 mm".
7. **Make solid:** run it on a model that overlaps itself. The result should be solid.
8. **Sculpt:** make one Inflate stroke on the bunny. Only a small patch should move.
9. **Transform:** scale the model by handle, with Snap off and then on. Undo should work.
10. **Parts library:** place a 10 mm part on the bunny. It should be 10 mm.
11. **Units:** type `5 cm + 2 mm` into a length field. It should show 52 mm.
12. **Export STL**, then re-import it: the size should be the same, in mm.
13. **A refusal:** Combine a Hole with a model that overlaps itself. The refusal should appear in the Combine panel, name the model, and offer "Run Make solid first".
14. Quit and reopen the app. The import unit you chose last time should be remembered.
