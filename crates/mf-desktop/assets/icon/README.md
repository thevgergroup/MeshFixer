# App icon

- `meshfixer-rabbit-source.png` is the master artwork: a low-poly rabbit. It nods to Meshmixer's bunny without copying it, and was supplied by the owner on 2026-11-18.
- `meshfixer-1024.png` is the master with its corners made transparent, sized to the macOS icon grid (an 824 px tile on a 1024 px canvas).
- Every other icon file is generated from `meshfixer-1024.png`:
  - `MeshFixer.icns` for macOS, via `iconutil`;
  - `MeshFixer.ico` for Windows;
  - `meshfixer-256.png`, the window icon compiled into the app;
  - `meshfixer-512.png`.
